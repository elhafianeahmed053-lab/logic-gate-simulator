Inside a CMOS gate

Each transistor is a switch. An nMOS switch is ON when its gate input is 1, and a pMOS switch is ON when its gate input is 0. Pull-up pMOS switches connect the output to 3 V, and pull-down nMOS switches connect it to 0 V.

Why NAND and NOR are universal

A gate is universal when it can build AND, OR and NOT on its own, so any circuit can be made from that one gate. This page builds each one and checks it against the real gate for every input.

This page and the Python command-line tool share the same logic and the same tests. Run python main.py web to open this page from the Python project.
